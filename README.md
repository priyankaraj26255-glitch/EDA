Titanic Dataset – EDA
Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to understand passenger information, survival patterns, and missing values.

Objectives
Load the Titanic CSV using Pandas.
Generate descriptive statistics.
Analyze missing values.
Create visualizations using Matplotlib and Seaborn.
Document key findings.
Export the notebook as HTML.
Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook
Run the Project

Install dependencies:

bash
pip install pandas numpy matplotlib seaborn jupyter


Start Jupyter Notebook:

bash
jupyter notebook

Export to HTML
bash
jupyter nbconvert --to html Titanic_EDA.ipynb

Deliverables
EDA Jupyter Notebook
Data visualizations
Missing value summary
HTML report
Conclusion

The project explores the Titanic dataset and identifies important patterns and insights related to passenger survival.
